# ADR-012: 収益モデルは買い切り(全機能)。広告・IAP・サブスクなし

- 状態: 採用 (2026-10-25、オーナー決定)
- 関連: 設計書 §0.1(課金は対象外=v1機能として課金実装は持たない) / §12(広告SDKなし・ネットワーク権限なし)

## 決定
- 有料アプリの買い切り。無料試用・ページ数制限・機能ロック・アプリ内課金・サブスクは設けない。
- 広告SDK(AdMob含む)は入れない。提供されたAdMob ID(PageMint_bannerAd)は**使用せず、リポジトリにも記載しない**。AdMobにmacOS用SDKは無い。
- 暫定価格: 1,500円前後 (発売記念で数週間 980円前後の案)。実際の価格はApp Store Connectの価格帯から選ぶ。市場調査・競合価格の確認は未実施。
- 課金は決済プラットフォーム側で完結し、アプリ内に課金コード・ネットワーク通信を持たない。
